# Support

## Product questions

Open a GitHub issue: https://github.com/shahrivar88/SmartProcess_ERPNext_Calender/issues

Include:

- Frappe version
- ERPNext version if installed
- App version from `jalali_shamsi_datepicker/__init__.py`
- Whether `Enable Shamsi (Jalali) Calendar` is on
- The field type: `Date`, `Datetime` or `Time`
- The typed value and the stored value

## Installation questions

Read [docs/INSTALLATION.md](docs/INSTALLATION.md) first. The GitHub repository name is not the Frappe app name.

## Security reports

See [SECURITY.md](SECURITY.md).

## What this project does not support

- Edits to Frappe or ERPNext core
- Production deploy from this repository without a separate release review
- Untested major Frappe versions
- Automatic vendor calendar upgrades
